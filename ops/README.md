# Velixon authority operations

This folder is the review-controlled operating layer for backlink, directory, partner, podcast, newsletter, and guest-article opportunities. It is intentionally outside `public/` and is never shipped with the website.

## Workflow

1. Add an opportunity to `backlink-opportunities.csv` with a source URL and relevance note.
2. Verify the current submission requirements on the official organization website.
3. Move the record to `Qualified` only when Velixon has truthful evidence for every required claim.
4. Move it to `Ready to Submit` only after the copy and target page have been reviewed.
5. Do not submit or send outreach without explicit approval.
6. Record the live placement URL and follow-up date. Never count an application as a published backlink.

Allowed statuses: `Researching`, `Qualified`, `Ready to Submit`, `Submitted`, `Follow-Up Required`, `In Discussion`, `Approved`, `Published`, `Rejected`, `Not Relevant`, `Archived`.

The initial rows are a working queue based on the current off-site authority plan, not claims of eligibility, partnership, approval, or placement. Re-verify every official URL and requirement immediately before outreach.

## Source-to-funnel rule

Use a campaign URL for every approved placement, for example:

`https://velixon.net/automation-assessment/?utm_source=partner-name&utm_medium=referral&utm_campaign=authority`

Link to the most relevant guide, integration, case study, calculator, or industry page when it answers the audience's question better than the homepage. The site preserves first-touch attribution through the assessment and proposal request.
