# Velixon Audit Brand Film

An 18-second, silent 960×540 motion piece for the Velixon Free Business Systems Audit.

## Preview

```console
npm run dev
```

Open the `VelixonAudit` composition in Remotion Studio.

## Validate

```console
npm run lint
npm run build
```

## Export

```console
npm run render
```

The finished H.264 video is written to `output/velixon-audit-promo.mp4`.

To export the final CTA as a poster image:

```console
npm run still
```

## Creative direction

- Near-black and violet Velixon palette
- Self-hosted Outfit Variable typography
- Five connected audit areas
- Audit-first call to action
- No unsupported metrics, testimonials, or guarantees
- Intentionally silent for autoplay-safe web and social use

The Outfit font is distributed under the SIL Open Font License; a copy is in `public/OFL-Outfit.txt`.
